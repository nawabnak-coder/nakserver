# Md Nawab Ali Khan - Portfolio Website

A professional portfolio website showcasing my skills, projects, and experience as a Java Full Stack Developer.

## Live Demo

[View Live Website](https://nawabnak-coder.github.io/nakserver/web/index.html)

## Features

- Responsive design that works on all devices
- Clean and professional UI
- Skills section with progress bars
- Project showcase with descriptions
- Contact information
- Downloadable CV

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap (optional - if used)

## Sections

1. **Home**: Introduction with name, title, and call-to-action buttons
2. **About**: Personal information and background
3. **Skills**: Technical skills with proficiency indicators
4. **Projects**: Portfolio projects with descriptions and technologies
5. **Contact**: Contact information and location details

## Setup Instructions

1. Clone or download the project files
2. Open `index.html` in a web browser
3. Customize the content with your personal information

## Customization

To personalize this portfolio:

1. Replace the developer image with your own photo
2. Update personal information in the About section
3. Modify skills and proficiency levels
4. Add your actual projects with descriptions
5. Update contact information
6. Replace the CV file with your actual resume

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
